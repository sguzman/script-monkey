# Userscripts

Tampermonkey / Greasemonkey-style browser scripts live here.

Each script stays in its own directory and should use a `.user.js` entrypoint so it can be installed directly by a userscript manager.

Current projects:

- `youtube-play-all/`
- `duolingo-qol/`
- `scribd-downloader/`
- `libgen-filter/`
